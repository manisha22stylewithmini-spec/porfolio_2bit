# Manisha Baroliya — Portfolio

A pixel-art, game-inspired portfolio for Manisha Baroliya, Product & UX/UI Designer.

- **Hero** with a looping skills ticker
- **Design Journey** — scroll-pinned career milestones that unlock as you scroll
- **Design Impact** — measured results and process
- **Selected Projects Leaderboard** — swipeable carousel of live builds
- **Fresh on Behance** — case studies
- **Designer Quest** — a playable platformer about shipping a product (run, jump, crawl, stop at the red light)

## Run locally

It is a static site — no build step.

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765

## Files

- `index.html` — page, styles and page scripts
- `game.js` — the Designer Quest game
- `img/` — illustrations, stickers and project screenshots
